# MELA SKIN · Pub « papier carton » (voix Marion, 2 min 17)

Référence : vidéo 9:16 en papier découpé / carton kraft, sous-titres mot par mot. **43 plans** calés sur ta voix off.

## Mode d'emploi

1. Génère chaque image en **9:16** (Nano Banana / Recraft) avec `STYLE` + le prompt du plan. Pour les plans qui disent `@image1`, joins le packshot du sérum.
2. Nomme-les `images/S01.png` … `images/S43.png` (jpg/webp ok).
3. Lance `python3 build.py chemin/voix.mp3` → `pub.mp4` (720×1280, mouvement de caméra lent, sous-titres, voix).

Sans image, le script produit une version test (fond kraft numéroté) pour vérifier le timing.
