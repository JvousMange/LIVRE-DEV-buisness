# MELA SKIN : plans en code (concept → image de départ → image d'arrivée → action)

Règle : **1 phrase = 1 idée = 1 action**. L'image d'arrivée d'un plan = image de départ du suivant quand c'est possible (raccord dans l'image, pas de coupe sèche).
Motifs : visage de face ou de 3/4 (peau mate, taches noires) · pastille de peau (loupe) · usine à mélanine · iceberg (tache visible / racine sous la peau) · panneaux pour chiffres et actifs.
